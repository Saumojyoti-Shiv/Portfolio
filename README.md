## Overview

A fully interactive, animation-driven personal portfolio built with **React**, **TypeScript**, and **Vite**. Designed to showcase work through immersive web experiences rather than a traditional static page.

### Highlights

- **3D Physics Wordmark Preloader** — rigid-body letter simulation using canvas-based physics
- **WebGL Particle Portrait** — interactive particle system that reacts to mouse movement
- **Scroll-driven Typography** — smooth GSAP-powered animations tied to scroll position
- **Ricochet Playground** — interactive canvas physics toy
- **Certifications Showcase** — scrollable carousel of verified credentials
- **Contact Section** — video background with social and email links

## Running Locally

**Prerequisites:** Node.js 18+

```bash
# 1. Clone the repository
git clone https://github.com/Saumojyoti-Shiv/Portfolio.git
cd Portfolio

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start local dev server on port 3000 |
| `npm run build` | Build for production (`/dist`) |
| `npm run preview` | Preview production build locally |
| `npm run lint` | Run TypeScript type checks |
